# xAPI Japan Profiles (Draft)

このリポジトリは、日本の教育DXにおける学習ログ（xAPI）の標準化を目指す「xAPI Japan Profiles」のドラフト版を管理しています。

## 概要

多様な教育プラットフォームやツール間で学習データを相互運用可能にするため、日本国内での利用を想定したxAPIプロファイルの定義を行っています。
本プロファイルは、各ドメイン（領域）ごとに分割して管理されています。

## リポジトリ構成

各ディレクトリは、特定のドメインごとのプロファイル定義を含んでいます。

- **assessment**: Assessment（CBT/デジタルドリル）に関連するプロファイル
- **ebook**: 電子書籍型デジタル教材（ebook）に関連するプロファイル
- **lms**: 学習管理システム (LMS) に関連するプロファイル
- **group-lst**: グループ学習や協働学習に関連するプロファイル
