xAPI Japan Profiles

日本の教育DXにおけるスタディ・ログを、領域をまたいで読み解ける共通表現へ。

概要を読む Profileを見る
Purpose

領域ごとの学習ログを、同じ読み方で扱うためのドラフトです。

本リポジトリでは、日本国内の教育DXで利用される学習ログを相互運用しやすくするため、xAPI 1.0.3を前提としたProfile定義を領域別に整理しています。

Profiles

公開中のv1.0.0 Profile

01 Assessment Profile CBTやデジタルドリルにおける開始、回答、終了などの学習ログを扱います。 読む 02 ebook Profile 電子書籍型デジタル教材の起動、表示、ページ移動、注釈などの操作ログを扱います。 読む 03 LMS Profile 学習課題の作成、配布、提出、評価といったLMS上の学習活動を扱います。 読む 04 Group Learning Support Tool Profile 協働学習におけるコメント、スタンプなど、他者との相互作用ログを扱います。 読む
